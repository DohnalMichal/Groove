# Groove — habit tracker

Portfolio-grade habit tracker s retro groovy vizuální identitou.

## Spuštění

```bash
npm run dev
```

Otevři [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind v4
- Vanilla state — žádné externí libs nad rámec defaultu, persistence v `localStorage`
